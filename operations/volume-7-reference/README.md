# Volume 7 reference operations

## Cadence

- weekly: Agent Platform/ADK release notes, security advisories and seven-day sources;
- per release: selected models, libraries, APIs, regions, quotas and deprecations;
- monthly: architecture guidance, official samples and lower-volatility controls;
- immediately: incident learning, support correction, breaking change or retirement.

## Broken or changed source

Mark the entry unqualified; preserve the last dated observation; find the current
primary page; compare semantic impact; map affected volumes/code/IaC/policy/model/
customers; test migration or containment; obtain reviews; publish with date; and
notify owners. Never silently replace a source or automatically mutate production.

## Incident use

The reference identifies terminology, evidence roots and diagnostic branches.
Use the customer's deployed inventory and runbook for exact values/actions. If a
fact is missing or contradictory, state `unknown`, contain safely and escalate to
the source owner or Google support rather than guessing.
