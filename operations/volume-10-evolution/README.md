# Volume 10 evolution operations

## Change watch

Route security/removal/retirement notices immediately; review high-volatility
release, location, quota and deprecation sources weekly; record exact observation
and semantic impact; maintain private customer/deployment inventory and deadlines.

## Migration containment

Freeze affected promotion; disable only unsafe actions/versions; preserve old and
candidate manifests/evidence; stop incompatible session/event admission; route or
drain by version envelope; keep target writes idempotent; reconcile unknown effects;
and use manual service where no safe compatible path exists.

## Retirement closure

Prove zero authorized traffic, no queued/callback/direct-revision path, revoked
identity/secret/policy/Registry access, retention-safe state/data disposition,
released capacity, updated docs/runbooks/inventory and named customer acceptance.
An endpoint returning no traffic is not retired while credentials or consumers remain.
