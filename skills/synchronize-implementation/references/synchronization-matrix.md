# Synchronization matrix

| Changed concern | Inspect and normally update |
|---|---|
| product/API/version | chapter, `references/versions.json`, dependency pin, code, eval, migration |
| IAM/identity/action | architecture, Terraform, policy, negative tests, audit, incident runbook |
| network/data location | physical diagram, Terraform, policy, failure test, recovery, customer constraint |
| workflow/tool/state | contract, implementation, idempotency/reconciliation tests, telemetry, runbook |
| SLO/reliability | load/failure tests, alerts, dashboard queries, runbook, capacity/cost |
| customer delivery | workshop, lab, qualification record, acceptance, handover competency |
| maturity/support | local warning, alternatives, risk acceptance, roadmap, evidence ledger |

Documentation-only is valid only when the impact manifest explains why code, infrastructure, tests, labs, and operations remain correct.
