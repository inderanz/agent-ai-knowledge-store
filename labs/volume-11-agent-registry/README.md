# Volume 11 lab — governed catalog from registration to revocation

In an authorized sandbox, enable the Agent Registry API, register one A2A agent,
one MCP server and one HTTPS endpoint, inspect their projections, search them,
create only supported bindings, resolve from a pinned ADK release, then route the
destination through Gateway. Inject duplicate names, an invalid URL, misleading
tool annotations, a dead endpoint and an unauthorized editor; prove the pipeline
or runtime rejects each case. Revoke the destination and measure cache/drift
convergence. Preserve CLI/API outputs, IAM policy, health results, audit logs and
the exact source revision. Never use production credentials or customer data.

The supplied qualification record is intentionally incomplete and must fail the
production validator. Cleanup means deleting lab registrations/bindings and
confirming no agent can resolve or invoke them; retain the evidence per policy.
