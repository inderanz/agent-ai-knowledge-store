# Volume 15 lab — governed enterprise assistant vertical slice

In a licensed sandbox, decide location and CMEK before app creation; create a
non-production app and access-controlled data store; grant app-level access to a
test cohort after removing conflicting broad project access. Ingest synthetic
documents with positive and negative ACL cases. Measure retrieval/answer quality,
citations, latency, denial leakage and prompt-injection resilience. If supported
and approved, import one Registry MCP resource and prove Gateway egress policy.
Enable observability, rehearse connector failure/reindex and export/exit.

Never ingest customer production data for this lab. Delete the app/data stores,
test identities and imported resources after retention-approved evidence export.
The example record intentionally cannot authorize production.
