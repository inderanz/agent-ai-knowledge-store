# Repository roadmap

The roadmap is issue-driven. Each volume receives a GitHub milestone; each chapter is independently researched, implemented, reviewed, and merged.

- [Open roadmap issues](https://github.com/inderanz/agent-ai-knowledge-store/issues)
- [Volume milestones](https://github.com/inderanz/agent-ai-knowledge-store/milestones)

## Bootstrap workstreams

1. Repository bootstrap and contribution controls.
2. Documentation and classification standards.
3. Architecture and Mermaid standards.
4. ADR conventions.
5. Terraform standards and reference modules.
6. Python and testing standards.
7. CI/CD and upstream freshness automation.

## Volume sequence

| Volume | Outcome |
|---|---|
| 1 — Foundations | Shared vocabulary, platform principles, capability model, and decision framework |
| 2 — Platform | Organization, projects, network, governance, data, and control-plane architecture |
| 3 — ADK | ADK 2.x application, graph, tool, state, evaluation, and testing engineering |
| 4 — Runtime | Agent Runtime, Cloud Run, GKE, release, scaling, and workload placement |
| 5 — Security | Identity, gateway, registry, Model Armor, Cloud Armor, IAM, data, and threat controls |
| 6 — SRE | Observability, SLOs, incidents, capacity, recovery, DR, and cost |
| 7 — Reference | Service selection, schemas, APIs, configuration, troubleshooting, and compatibility |
| 8 — Industries | Regulated industry reference architectures and control overlays |
| 9 — FDE | Discovery, workshops, delivery phases, decision records, and handover |
| 10 — Evolution | Upgrades, deprecations, migrations, drift detection, and content lifecycle |

## Definition of done

A milestone is complete only when every chapter is Approved, runnable artifacts pass CI, source freshness is within policy, and the volume-level production checklist is signed off by the required reviewers.
